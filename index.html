Improvement Changelog

StageWhat I triedEvidenceDecision / Learning
BaselineSingle prompt to LLM: "Correct this pronunciation: [text]"Generic feedback, no memory, same errors repeatedEstablished starting point. LLM alone is not enough for adaptive learning.
Iteration 15 sequential "agents" (transcriber, analyzer, memory, generator, verifier) with 2 parallel audio pipelines (MediaRecorder + SpeechRecognition)Feature never completed: recording and transcription competed for the mic; the workflow never ranRemoved. Multiple agents + dual audio pipeline = fragile. Broke in real use.
Iteration 2Collapsing into ONE agent with 5 skills, single audio pipeline (SpeechRecognition only), plus typed-text fallbackFull cycle completes: speak → transcribe → score → memory → exercise → verify. Fallback guarantees demo.Kept. One agent, one pipeline, one source of truth. Reliability beats architectural purity.
FinalSingle agent, single pipeline, persistent memory (localStorage), demo-safe fallback89% avg accuracy, personalized exercises, stateful memory, zero-cost, runs offlineMain contribution: Memory as the differentiator. Before adding more AI, add memory.
