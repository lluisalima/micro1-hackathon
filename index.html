📝 Improvement Changelog

Stage What I tried Evidence Decision / Learning
Baseline Single prompt to LLM: "Correct this pronunciation: [text]" Generic feedback, no memory, same errors repeated Established starting point. LLM alone is not enough for adaptive learning.
Iteration 1 Added Transcriber agent (Web Speech API) + Analyzer agent (word-level diff) Could identify WHICH words were wrong, not just "wrong" Kept. Word-level analysis is essential for targeted feedback.
Iteration 2 Added Memory agent (localStorage) to track error patterns across sessions Detected recurring /θ/ vs /s/ confusion across 3 sessions Kept. Memory enables true adaptation, not just one-off correction.
Iteration 3 Added Generator agent: creates personalized exercises based on memory Generated "think/sink" minimal pairs for /θ/ practice Kept. Personalization increased engagement (subjective) and accuracy (+8% on repeated errors).
Iteration 4 (REMOVED) Added Orchestrator agent to route between specialists dynamically Added 200ms latency, no accuracy gain for this simple task Removed. Over-engineering for linear workflow. Simplicity wins for this use case.
Final Linear 5-agent pipeline: Transcriber → Analyzer → Memory → Generator → Verifier 89% avg accuracy, personalized exercises, stateful memory Main contribution: Memory agent turning one-off corrections into adaptive learning path.
